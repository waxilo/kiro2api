> 现在可以直接在 Kiro2API 里登录 Kiro 了 —— 用 AWS Builder ID 或企业 IAM Identity Center 走一次设备码授权就行，不用再先装 Kiro IDE、也不用敲 `kiro-cli login`。

- 凭据卡片新增「登录」：选 Builder ID 或 IAM Identity Center，弹出验证码并自动打开浏览器，确认后凭据自动保存、界面随即刷新
- 企业 IdC 可填自己的 Start URL 与区域；Builder ID 不需要填，用的是个人 AWS 账号
- 这份凭据存在 Kiro2API 自己的数据目录里，**不覆盖也不顶掉 Kiro IDE / kiro-cli 的登录** —— 两边各自刷新同一个令牌会互相踢下线，所以刻意分开存
- 已经用 Kiro2API 登录过时，凭据卡片改显示「退出登录」；退出只删自己的凭据，之后照旧读 IDE / CLI 的
- 登录成功或退出时代理若在运行，会按原端口自动重启一次接上新凭据，端口和已接入的客户端都不用改
- 登录进行中可以关掉弹窗放弃这次登录，验证码过期也会明确提示，不会留下一个默默轮询的后台任务
