> 模型现在能真正看到你贴的图和 PDF 了 —— 以前这些内容要么被客户端拦住，要么在路上被悄悄丢掉。

- 在 Codex 里贴图不再被判定为「模型不支持」：模型目录里的输入能力改成按上游真实支持的来写，能看图的模型会正常显示可发图（升级后第一次同步模型时自动更新目录，不用重新点「接入」）
- PDF 附件可以真读到了：Anthropic 的 `document`、OpenAI 的 `file`、Responses 的 `input_file` 三种写法都支持，模型能准确回答文件里的内容
- 文本类附件（txt / md / csv / json）直接把内容并进消息，不依赖上游是否解析
- 公网图片链接现在由本应用代下载后转成内联图片，三种协议行为一致 —— 以前 Anthropic 协议会直接报错、OpenAI 协议会默默丢图
- 读不到的附件也会说一声：只有文件 ID、文件超过 4 MB、格式不支持时，会给出一句「这里有个附件但读不到」，不再无声消失
- 代下载带安全限制：只走 http / https、拒绝内网地址、10 秒超时、单张图最大 5 MB
- 上游以后新增别的输入类型（比如视频）也不会把模型目录写坏，未知类型会被忽略
