> 本版为 macOS 补齐「重启 Codex 应用」：此前该按钮只在 Windows 可用，mac 上接入 Codex 后只能手动退出再打开 ChatGPT。

- macOS 按 bundle id（`com.openai.*`）识别 Codex（ChatGPT）桌面应用，兼容 codex / chatgpt / chat 三代命名
- 重启流程：TERM 请求退出 → 最多等 4 秒 → 超时才强杀 → `open -b` 按原身份拉起，全程不弹系统授权框
- 终端里跑的 codex CLI 不会被误伤：只有命令行包含应用 bundle 路径的进程才会被结束
- 应用在跑时的「重启生效」确认弹窗，mac 上改为真实探测（此前是恒提示）
