> Codex 里不再只有 GPT：Claude、DeepSeek、GLM 等模型现在都能接入并正常对话。

- 三方接入的 Codex 页签会列出模型清单里的全部模型，不再只剩 `gpt-` 开头那几条
- 推理档位按模型自己的能力声明：Claude 可选低 / 中 / 高三档；DeepSeek、GLM、Qwen 这类不收 effort 的模型不显示档位，代理侧也不会发这个字段
- 用户选的档位若不在该模型支持范围内，自动退到它能给的最高档，不会把上游不认的值打过去
- `auto` 仍然不写进 Codex 目录：它是 Kiro 的自选模型占位，能力无法声明
- 已接入过的机器重新点一次「应用」刷新目录，再重启 Codex 就能在选择器里看到新模型
