> 本版把 Codex 接入从「一键写入」升级为模型目录自由勾选，应用与清空后可一键重启 Codex 生效，模型清单也补上了上游消耗倍率。

- Codex 接入卡新增模型多选网格：从可用模型清单里勾选要暴露给 Codex 的模型，点「应用」一次写入 provider、密钥、模型目录与默认模型；没动勾选直接「应用」= 按目录现状修复重接，不会误动模型
- Codex 只在启动时读一次配置：应用 / 清空之后弹窗确认，可一键强制重启 Codex 应用（结束其进程树后按原身份拉起），不重启就是换不了模型
- 勾成空清单再应用，或直接点「清空」：本应用的 provider、密钥与模型目录一并移除，不留指向本应用的痕迹；ChatGPT 登录与其它配置原样保留
- WorkBuddy 接入卡同样补上「清空」按钮：一键移除清单里全部指向本应用的模型条目
- Codex 桌面端只认 GPT 系模型：模型清单与勾选网格自动只列 gpt- 开头的模型；旧目录里残留的其它模型会标「Codex 不支持」，取消勾选并应用即可清出
- 模型卡显示上游消耗倍率（如 ×1.3，0 显示「免费」，还没同步到的省略不占位），随「从上游同步」刷新
- 「可用模型」分区改用与三方接入一致的模型卡网格，整卡点击即复制模型名
