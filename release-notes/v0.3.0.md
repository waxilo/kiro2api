> 本次更新把几处「点了会卡住 / 点了不知道在干嘛」的地方收拾了一遍：
> 刷新凭据不再锁住整个页面，检查更新可以自己挑线路，
> 概览页那颗来路不明的「刷新」也去掉了。

- **刷新凭据不再锁页面。** 它等的是最长 30 秒的上游请求，以前这段时间会把你整页的按钮
  一起变灰。现在只有「会改配置」的动作（启停代理、改端口、重置密钥、同步模型）才互相排队，
  刷新凭据和查询额度只占用自己那一块 —— 它跑着的时候，启动代理、复制地址、查额度都照常可用。
- **应用更新可以手动切换下载线路。** 「应用更新」分区多了一张卡片，可选
  **自动（探测最快）/ GitHub 直连 / ghfast.top / gh-proxy.com / mirror.ghproxy.com**，
  选择会记住。选「直连」就一个字节都不改写；固定镜像不可用时自动回退，并在界面上
  写清「你选的哪个不可用、本次实际走的哪个」——不会显示一个其实没生效的选择。
- **可用模型支持搜索，单击模型名即可复制。** 清单变长之后不用再拿眼睛扫；
  搜索框只接受英文，因为模型名本来就只有 ASCII ——
  中文输入法选了候选词也不会把字塞进来（粘贴整段中文同样会被挡下并说明原因）。
- **概览页的「刷新」按钮去掉了。** 它只是重读一遍本地状态，而首屏、每个动作收尾、
  后端推来事件、窗口重新可见/重新获得焦点都会自动做。凭据没找到时，
  「Kiro 凭据」卡片里的按钮会换成**「重新检测」** —— 在应用外面跑完 `kiro-cli login`
  回来点它一下即可。
- **失败与提示改为浮层（toast）。** 以前失败会在页面顶部插一条横幅，把内容整体推下去、
  按钮挪位，读起来像「页面抖了一下」。现在一律浮在右上角，页面结构不再因为一条错误而改变。
