> 本版把额度开放给第三方客户端：WorkBuddy 勾选即接入，Codex CLI 一键写入配置，并新增 Responses 协议入口。

- 新增「三方接入」分区：WorkBuddy 把可用模型勾选写入它的自定义模型清单，取消勾选即移除，点「应用」一次生效（「恢复」放弃未应用的改动）；分区只管理指向本应用的条目，配给其它服务的模型不可见也不可动
- 支持 Codex CLI 一键接入：自动写入 `~/.codex/config.toml` 的 provider 并把密钥同步进 `auth.json`，只动与本应用相关的条目，ChatGPT 登录与其它配置保持原样；模型在 Codex 里用 `/model` 切换
- 代理新增 OpenAI Responses 协议入口 `POST /openai/v1/responses`（Codex 2026-02 起只认该协议）：支持流式事件、工具调用与结果回传
- 接入地址与密钥在代理停止时也能复制：地址由配置端口决定，客户端可以提前配好，代理一启动即通
- 应用开着时后台定期维护：额度刷新、凭据临期自动续签、更新检查不再只在启动时各跑一次；全部静默进行，失败不打扰
- 凭据刷新全程分阶段耗时写入诊断日志 `kiro-debug.log`（排查「刷新凭据超时」用，文件可直接删除）
- 额度页显示「上次刷新」时刻，用量百分比不再出现浮点尾数；界面后台重绘不再打断正在输入的光标
- 「双协议接入」更名「协议接入」，两张协议卡片改为上下堆叠，按协议配主题色图标
