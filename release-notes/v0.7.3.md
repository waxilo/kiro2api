> 本版修复 macOS 上只安装 kiro-cli（未装 Kiro IDE）时应用误报「未找到 Kiro 凭据」的问题。

- 新版 kiro-cli（≥ 2.31）把登录凭据存进自己的密钥库（macOS：`~/Library/Application Support/kiro-cli/data.sqlite3`），不再写 Kiro IDE 的 `~/.aws/sso/cache/kiro-auth-token.json`，导致只装 CLI 的机器上凭据永远扫不到
- 应用检测不到凭据文件时，会自动从 kiro-cli 的凭据库只读桥接出令牌与 client registration 文件（0600 权限，不改动 kiro-cli 的任何数据），续期链路原样可用
- 桥接仅在凭据文件缺失时触发，绝不覆盖已有的 IDE 凭据；kiro-cli 重新登录后自动跟随重试
- 附 `scripts/bridge-kiro-cli-credentials.py`：旧版本用户可手动执行完成同样的桥接
