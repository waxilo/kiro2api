> 本版不再把「账户里没有的模型」悄悄换成别的模型，而是直接告诉你是哪个模型不可用、能用哪些；登录弹窗也开始记住你用过的企业域。

- 点了账户里没有的模型时，请求直接报错并列出这个账户真实可用的模型，不再悄悄换成默认模型上送 —— 以前那种「以为在用 Claude、实际花的是另一个模型的额度」不会再出现
- 模型名不再按关键字猜代次：名字里带 `opus` / `haiku` / `sonnet` 不会被自动替换成别的型号；只保留公共 ID 到上游 ID 的形态转换，以及同代的日期后缀（`claude-sonnet-4-5-20250929` 仍对应 `claude-sonnet-4.5`）
- 客户端压根没指定模型时，照旧用账户里的默认模型
- 响应里不再带 `X-Kiro-Actual-Model` / `X-Kiro-Requested-Model` 两个诊断头 —— 既然不会再换模型，它们就没有意义了
- 登录弹窗的 Start URL 右侧多了下拉箭头，列出用过的企业域，点一条就把 URL 和区域一起填回去（最多记 8 个，最近用过的排最前）
- 升级前用过的域也能选到：会从已有的登录凭据里读出来，不需要重新登一次
- 下拉浮层浮在输入框之上，展开收起都不会把登录弹窗撑大
