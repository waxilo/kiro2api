> 本版修好 Codex 的「取消接入」：还原之后 Codex 里仍显示 kiro2api 账号的问题没有了 —— 接入不再碰你的登录态，取消时也会把旧版本写进去的痕迹一并清掉。

- Codex 接入不再改动 `auth.json`：密钥改为写进 `config.toml` 的 provider 条目，你的官方登录（ChatGPT 账号）保持原样，界面里的账号不会再被顶成 kiro2api
- 「取消接入」能把旧版本留下的密钥清干净 —— 即使你重置过代理密钥、或换了机器也认得出来；同时撤掉只属于 API key 的身份标记，退出重开 Codex 就是官方账号
- 取消接入不再把你自己的密钥写回成 kiro2api 的密钥（旧版快照会把它误记成「你原本的密钥」）
- 之前接管过 Codex 的用户：点一次「应用」即可迁移到新写法，之后取消接入就是干净还原
- 提醒：macOS 上若 `config.toml` 配了 `cli_auth_credentials_store = "keyring"`，凭据存在钥匙串里，需要 `codex logout` 后重新登录一次
